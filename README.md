# Hi, I'm Ran! 👋

Software team lead, R&D group manager and software architect based in Israel, hands-on in backend. I've spent the last nine years building mission-critical distributed systems: four years as a developer, then leading teams and groups of up to 36 people while staying close to the design and the code.

### What I've worked on

- Moving a family of legacy C# / .NET desktop products to TypeScript and Python microservices on RabbitMQ, MongoDB and Kubernetes, with old and new systems running side by side until the old one could go.
- Platforms that run unchanged from development to production, where a new integration ships as configuration instead of a release.
- Continuous deployment into air-gapped environments, with automated acceptance tests at every site.
- Reliability work driven by data: tracking failures error by error, SLOs, and on-call that spots problems in minutes.

### What interests me

- System design and its trade-offs: where the complexity lives, and what it costs later.
- Event-driven architecture and messaging.
- Taking legacy systems apart without stopping them.
- AI-assisted development. I run my own agent-based assistant on Claude Code, with custom skills, scoped subagents and MCP connectors.
